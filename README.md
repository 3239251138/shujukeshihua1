# 数据可视化平台

一个功能丰富的数据可视化平台，支持多种图表类型和交互式操作。

## 功能特性

### 基础图表
- 📈 **折线图** - 气温变化趋势、销售数据等
- 📊 **柱形图** - 商品销售对比、收入数据等
- 🥧 **饼图** - 预算分配比例、市场份额等
- 🔵 **散点图** - 变量相关性分析
- 📋 **直方图** - 数据分布情况

### 第3章交互式图表
- **正弦余弦函数** - 可调节频率和振幅
- **带刻度的函数图** - 支持π刻度显示
- **电影票房排行榜** - 实时编辑数据，自动更新图表

### 交互功能
- 动画效果支持
- 实时数据更新
- 响应式设计
- 文件上传支持（CSV、JSON、Excel）

## 技术栈

- **前端框架**: 原生HTML/CSS/JavaScript
- **图表库**: Chart.js
- **动画库**: Anime.js
- **样式**: 响应式CSS Grid布局

## 使用说明

### 图表切换
- 点击顶部导航栏切换不同类型的图表
- 每个图表都有多种数据模式可供选择

### 交互操作
- 第3章图表支持滑块调节参数
- 电影票房数据可直接在表格中编辑
- 点击"播放动画"按钮查看动态效果

### 文件上传
- 支持上传CSV、JSON、Excel格式文件
- 系统将自动解析数据并生成可视化图表

## 开发说明

### 添加新图表类型
1. 在HTML中添加新的图表容器
2. 在JavaScript中初始化图表配置
3. 添加对应的数据生成函数

### 自定义样式
- 主要样式定义在 `<style>` 标签中
- 使用CSS变量便于主题定制
